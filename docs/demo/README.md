# Material de demo — Devin no Royal Reserve Bank

Ambiente e roteiro para conduzir uma demo M1 (primeira reunião técnica) usando este repositório como
caso real: plataforma bancária Java 17 / Spring Boot com 7 microsserviços.

| Arquivo | Para quê |
|---|---|
| [ROTEIRO-M1.md](./ROTEIRO-M1.md) | O roteiro da reunião, etapa por etapa, com tempos e falas |
| [PROMPTS.md](./PROMPTS.md) | Prompts prontos para copiar e colar, na ordem do roteiro |
| [FAQ-OBJECOES.md](./FAQ-OBJECOES.md) | Perguntas e objeções recorrentes com respostas |
| [KNOWLEDGE-E-PLAYBOOKS.md](./KNOWLEDGE-E-PLAYBOOKS.md) | Knowledge notes, playbook e automações para provisionar antes |
| [CHECKLIST-PRE-DEMO.md](./CHECKLIST-PRE-DEMO.md) | O que verificar em D-1 e 1h antes, com comandos validados |
| [demo-ui/](./demo-ui) | UI estática mínima usada como evidência visual do fluxo de negócio |

Comece pelo checklist. O roteiro pressupõe repositório indexado, knowledge/playbook provisionados e a
stack local no ar.
